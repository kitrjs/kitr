# @kitr/kit-docs

**Docs kit.** Start a docs site from markdown files: a sidebar, search, dark mode and copies for coding agents, prerendered to static HTML.

```sh
pnpm dlx @kitr/kitr new my-app --kit docs
```

Read the guide at https://kitr.dev/kits/docs.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
