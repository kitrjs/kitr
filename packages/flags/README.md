# @kitr/flags

**Feature flags.** Turn features on for some users and off for others, with the same answer on the server and in the browser.

```sh
pnpm kitr add flags
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/flags`.

Built on OpenFeature.

Read the guide at https://kitr.dev/packages/flags.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
