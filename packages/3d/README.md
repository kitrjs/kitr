# @kitr/3d

**3D.** Render 3D scenes and models that stay smooth on phones and fall back when WebGL is missing.

```sh
pnpm kitr add 3d
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/3d`.

Built on @react-three/fiber, three.

Read the guide at https://kitr.dev/packages/3d.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
