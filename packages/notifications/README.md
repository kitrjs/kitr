# @kitr/notifications

**Notifications.** Ask for permission and show local or scheduled notifications that open the right page when tapped.

```sh
pnpm kitr add notifications
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/notifications`.

Read the guide at https://kitr.dev/packages/notifications.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
