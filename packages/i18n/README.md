# @kitr/i18n

**Translations.** Translate your app into several languages with typed keys.

```sh
pnpm kitr add i18n
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/i18n`.

Built on react-i18next.

Read the guide at https://kitr.dev/packages/i18n.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
