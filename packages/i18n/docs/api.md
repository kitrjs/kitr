## kitr/i18n

### matchLocale

```ts
function matchLocale(candidates: string | readonly string[], supported: string[]): string | undefined;
```

Pick the best supported locale from an `Accept-Language` header (server) or a language list.

### I18nConfig

```ts
interface I18nConfig extends Omit<InitOptions, 'resources' | 'lng'> {
  /** `{ en: { common: { hello: 'Hello' } } }` */
  resources: Record<string, Record<string, Record<string, unknown>>>;
  defaultLocale: string;
  locales?: string[];
  /** Detect from `navigator.language` (client) or `Accept-Language` (server). Default true. */
  detect?: boolean;
  /** Query/cookie/storage key for an explicit choice. Default `locale`. */
  storageKey?: string;
}
```

### TranslationKeys

```ts
type TranslationKeys<R, Prefix extends string = ''> = {
  [K in keyof R & string]: R[K] extends string ? `${Prefix}${K}` : TranslationKeys<R[K], `${Prefix}${K}.`>;
}[keyof R & string];
```

Keys of a resource bundle as `namespace:key.path` strings, for typed `t()`.

## kitr/i18n/provider

### i18nProvider

```ts
const i18nProvider: KitrProvider;
```

Binds `i18n` from `config/i18n.ts` and wraps the tree in I18nextProvider.
