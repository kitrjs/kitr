# @kitr/server

**Server.** Run a Node server that starts, logs and shuts down cleanly.

```sh
pnpm kitr add server <name>
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/server`.

Built on h3.

Read the guide at https://kitr.dev/packages/server.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
