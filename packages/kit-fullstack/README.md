# @kitr/kit-fullstack

**Fullstack kit.** Start the app kit with a server-rendered site, an API server, actions and realtime channels.

```sh
pnpm dlx @kitr/kitr new my-app --kit fullstack
```

Read the guide at https://kitr.dev/docs/cli.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
