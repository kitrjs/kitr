# @kitr/api

**API routes.** Build JSON API routes with validation, and call them from the browser fully typed.

```sh
pnpm kitr add api
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/api`.

Built on h3.

Read the guide at https://kitr.dev/packages/api.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
