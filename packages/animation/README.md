# @kitr/animation

**Animation.** Animate components and page changes, and respect the visitor's reduced-motion setting.

```sh
pnpm kitr add animation
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/animation`.

Built on motion.

Read the guide at https://kitr.dev/packages/animation.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
