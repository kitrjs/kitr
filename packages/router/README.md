# @kitr/router

**Router.** Pages on the kitr route table, rendered by TanStack Router: typed links, loaders and guards. Web, desktop and mobile apps get it free.

```sh
pnpm kitr add router
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/router`.

Built on @tanstack/react-router.

Read the guide at https://kitr.dev/packages/router.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
