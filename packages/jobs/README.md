# @kitr/jobs

**Jobs.** Run work in the background or on a schedule, with retries when it fails.

```sh
pnpm kitr add jobs
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/jobs`.

Read the guide at https://kitr.dev/packages/jobs.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
