# @kitr/shield

**Shield.** Turn on the security basics every API needs: CORS, CSRF protection, safe headers and rate limits.

```sh
pnpm kitr add shield
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/shield`.

Read the guide at https://kitr.dev/packages/shield.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
