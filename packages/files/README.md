# @kitr/files

**Files.** Let people open, save and pick files on any platform, with a download fallback in older browsers.

```sh
pnpm kitr add files
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/files`.

Read the guide at https://kitr.dev/packages/files.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
