# @kitr/kitr

kitr: the CLI and the kitrrc.ts config for apps built from @kitr/* packages. Each package is installed with `kitr add <name>` and imported from `@kitr/<name>`.

```sh
pnpm dlx @kitr/kitr new my-app
```

Read the guide at https://kitr.dev.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
