# @kitr/forms

**Forms.** Build forms with validation, and show server errors next to the right field.

```sh
pnpm kitr add forms
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/forms`.

Built on react-hook-form.

Read the guide at https://kitr.dev/packages/forms.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
