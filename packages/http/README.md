# @kitr/http

**HTTP client.** Call a REST API with login tokens added for you and errors in one shape.

```sh
pnpm kitr add http
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/http`.

Built on ky.

Read the guide at https://kitr.dev/packages/http.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
