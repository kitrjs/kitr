# @kitr/monitoring

**Monitoring.** Catch errors in the browser and on the server, and see which user hit them and what they did first.

```sh
pnpm kitr add monitoring
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/monitoring`.

Built on Sentry.

Read the guide at https://kitr.dev/packages/monitoring.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
