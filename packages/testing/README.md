# @kitr/testing

**Testing.** Test components and API routes with everything already wired up.

```sh
pnpm kitr add testing
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/testing`.

Built on vitest, @testing-library/react.

Read the guide at https://kitr.dev/packages/testing.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
