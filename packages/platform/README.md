# @kitr/platform

**Platform.** Know where your app is running, whether it is online or in the background, and handle the back button and deep links.

```sh
pnpm kitr add platform
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/platform`.

Read the guide at https://kitr.dev/packages/platform.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
