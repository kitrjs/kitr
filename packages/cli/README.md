# @kitr/cli

The kitr CLI: new, add, remove, make:*, ui add, api:sync, doctor, eject, upgrade. Runs from flags with no prompts for agents and CI.

```sh
pnpm dlx @kitr/kitr new my-app
```

Read the guide at https://kitr.dev/packages/cli.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
