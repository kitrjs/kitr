# @kitr/kit-saas

**SaaS kit.** Start a logged-in product on its own API: sign-in, a guarded shell, a projects CRUD, analytics.

```sh
pnpm dlx @kitr/kitr new my-app --kit saas
```

Read the guide at https://kitr.dev/kits/saas.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
