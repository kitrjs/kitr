# @kitr/mocks

**Mocks.** Fake your API while you build the frontend or run tests.

```sh
pnpm kitr add mocks
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/mocks`.

Built on msw.

Read the guide at https://kitr.dev/packages/mocks.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
