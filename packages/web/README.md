# @kitr/web

**Web.** Ship to the browser as a static site, a single-page app or a server-rendered app, installable if you want.

```sh
pnpm kitr add web <name>
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/web`.

Built on Vite, TanStack Start, vite-plugin-pwa.

Read the guide at https://kitr.dev/packages/web.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
