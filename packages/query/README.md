# @kitr/query

**Query.** Load data from your API, keep it cached, and refresh it when something changes.

```sh
pnpm kitr add query
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/query`.

Built on @tanstack/react-query.

Read the guide at https://kitr.dev/packages/query.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
