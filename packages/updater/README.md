# @kitr/updater

**Updater.** Tell people a new version is ready and update the app in place, on the web, desktop and mobile.

```sh
pnpm kitr add updater
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/updater`.

Read the guide at https://kitr.dev/packages/updater.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
