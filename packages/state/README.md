# @kitr/state

**State.** Keep app-wide values like a cart or settings, and optionally save them in the browser.

```sh
pnpm kitr add state
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/state`.

Built on zustand.

Read the guide at https://kitr.dev/packages/state.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
