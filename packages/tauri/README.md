# @kitr/tauri

**Tauri.** Ship the same app to Windows, macOS and Linux as a small Tauri binary on the operating system's webview.

```sh
pnpm kitr add tauri <name>
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/tauri`.

Built on Tauri 2.

Read the guide at https://kitr.dev/packages/tauri.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
