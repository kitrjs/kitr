# @kitr/realtime

**Realtime.** Define a live channel once and push updates to every open screen, over WebSockets, Socket.IO or server events.

```sh
pnpm kitr add realtime
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/realtime`.

Built on crossws, partysocket, socket.io.

Read the guide at https://kitr.dev/packages/realtime.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
