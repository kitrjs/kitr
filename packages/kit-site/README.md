# @kitr/kit-site

**Site kit.** Start a marketing site: server-rendered, prerendered, SEO heads, i18n, a blog and a newsletter form.

```sh
pnpm dlx @kitr/kitr new my-app --kit site
```

Read the guide at https://kitr.dev/kits/site.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
