# @kitr/seo

**SEO.** Give every page a title, a share preview and a sitemap entry so search engines and chat apps show it well.

```sh
pnpm kitr add seo
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/seo`.

Read the guide at https://kitr.dev/packages/seo.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
