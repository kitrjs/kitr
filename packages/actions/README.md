# @kitr/actions

**Server actions.** Call server code straight from a component, like a form submit, without writing an API route.

```sh
pnpm kitr add actions
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/actions`.

Built on @tanstack/react-start.

Read the guide at https://kitr.dev/packages/actions.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
