# @kitr/consent

**Consent.** Ask for cookie and tracking consent once, and hold analytics and error reports until people agree.

```sh
pnpm kitr add consent
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/consent`.

Read the guide at https://kitr.dev/packages/consent.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
