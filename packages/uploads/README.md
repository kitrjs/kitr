# @kitr/uploads

**Uploads.** Accept file uploads with size limits, store them on disk or in the cloud, and show progress in the browser.

```sh
pnpm kitr add uploads
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/uploads`.

Read the guide at https://kitr.dev/packages/uploads.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
