# @kitr/theme

**Theme.** Light, dark and system themes with no flash on load, design tokens, toasts, and the components you copy into your app.

```sh
pnpm kitr add theme
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/theme`.

Built on CSS variables, shadcn/ui, sonner.

Read the guide at https://kitr.dev/packages/theme.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
