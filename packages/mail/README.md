# @kitr/mail

**Mail.** Write emails as React components, send them through your provider, and preview them in development.

```sh
pnpm kitr add mail
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/mail`.

Built on React Email.

Read the guide at https://kitr.dev/packages/mail.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
