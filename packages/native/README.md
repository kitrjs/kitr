# @kitr/native

**Native.** Clipboard, share sheet, haptics, location, camera and fingerprint unlock, each with a web fallback.

```sh
pnpm kitr add native
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/native`.

Read the guide at https://kitr.dev/packages/native.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
