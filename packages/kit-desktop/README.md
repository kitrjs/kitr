# @kitr/kit-desktop

**Desktop kit.** Start the app kit in an Electron shell with a typed IPC contract and native dialogs.

```sh
pnpm dlx @kitr/kitr new my-app --kit desktop
```

Read the guide at https://kitr.dev/kits/desktop.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
