# @kitr/kit-tauri

**Tauri kit.** Start the app kit in a Tauri shell with typed Rust commands and events from the same React app.

```sh
pnpm dlx @kitr/kitr new my-app --kit tauri
```

Read the guide at https://kitr.dev/docs/cli.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
