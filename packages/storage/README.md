# @kitr/storage

**Storage.** Save small values in the browser or in cookies with types, and read the same cookies on the server.

```sh
pnpm kitr add storage
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/storage`.

Built on localStorage, cookies.

Read the guide at https://kitr.dev/packages/storage.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
