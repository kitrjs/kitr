# @kitr/kit-app

**App kit.** Start with pages, data loading and styling, and add sign-in, forms or an API when you need them.

```sh
pnpm dlx @kitr/kitr new my-app --kit app
```

Read the guide at https://kitr.dev/kits/app.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
