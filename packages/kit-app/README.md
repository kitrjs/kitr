# @kitr/kit-app

**App kit.** Start a logged-in app on an external API: forms, tables, state, theme, auth, mocks and tests.

```sh
pnpm dlx kitr new my-app --kit app
```

Read the guide at https://kitr.dev/docs/cli.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
