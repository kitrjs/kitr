# @kitr/devtools

**Devtools.** Open a window that shows what every package is doing, from a floating button, a shortcut or a touch gesture. On in development; turn it on in production with one flag.

```sh
pnpm kitr add devtools
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/devtools`.

Read the guide at https://kitr.dev/packages/devtools.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
