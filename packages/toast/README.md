# @kitr/toast

**Toast.** Show short messages like "Saved" or "Could not send" from anywhere in your app, even outside React.

```sh
pnpm kitr add toast
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/toast`.

Built on sonner.

Read the guide at https://kitr.dev/packages/toast.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
