# @kitr/offline

**Offline.** Keep showing loaded data with no connection, and send queued changes when the network comes back.

```sh
pnpm kitr add offline
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/offline`.

Built on TanStack Query.

Read the guide at https://kitr.dev/packages/offline.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
