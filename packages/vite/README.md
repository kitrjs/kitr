# @kitr/vite

**Vite.** Build and serve the browser side of your app with Vite, wired to kitrrc.ts by one plugin.

```sh
pnpm kitr add vite
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/vite`.

Built on vite.

Read the guide at https://kitr.dev/packages/vite.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
