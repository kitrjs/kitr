# @kitr/table

**Tables.** Show rows of data with sorting, paging and filters that stay in the URL.

```sh
pnpm kitr add table
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/table`.

Built on @tanstack/react-table.

Read the guide at https://kitr.dev/packages/table.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
