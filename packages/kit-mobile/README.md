# @kitr/kit-mobile

**Mobile kit.** Start the app kit as an installable PWA and a Capacitor shell with native lifecycle hooks.

```sh
pnpm dlx @kitr/kitr new my-app --kit mobile
```

Read the guide at https://kitr.dev/docs/cli.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
