# @kitr/auth

**Auth.** Sign users in and out, protect pages, and check who can do what.

```sh
pnpm kitr add auth
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/auth`.

Read the guide at https://kitr.dev/packages/auth.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
