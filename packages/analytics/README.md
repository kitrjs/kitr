# @kitr/analytics

**Analytics.** Count page views and button clicks, and send them to the analytics service you choose.

```sh
pnpm kitr add analytics
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/analytics`.

Built on Google Analytics, Plausible, PostHog.

Read the guide at https://kitr.dev/packages/analytics.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
