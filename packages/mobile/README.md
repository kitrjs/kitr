# @kitr/mobile

**Mobile.** Ship the same app to iPhone and Android, with every kitr package switched to its native version.

```sh
pnpm kitr add mobile <name>
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/mobile`.

Built on Capacitor.

Read the guide at https://kitr.dev/packages/mobile.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
