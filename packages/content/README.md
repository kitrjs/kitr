# @kitr/content

**Content.** Write pages in markdown and get a docs site: highlighted code, a sidebar, search and copies for coding agents.

```sh
pnpm kitr add content
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/content`.

Built on unified, shiki.

Read the guide at https://kitr.dev/packages/content.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
