# @kitr/db

**Database.** Connect your database so every request can use it.

```sh
pnpm kitr add db
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/db`.

Read the guide at https://kitr.dev/packages/db.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
