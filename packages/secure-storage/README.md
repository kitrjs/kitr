# @kitr/secure-storage

**Secure storage.** Keep login tokens and secrets in the phone or computer's secure vault instead of plain storage.

```sh
pnpm kitr add secure-storage
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `@kitr/secure-storage`.

Read the guide at https://kitr.dev/packages/secure-storage.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
