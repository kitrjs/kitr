# @kitr/tailwind

**Tailwind.** Style with Tailwind CSS classes, already set up with kitr's colours.

```sh
pnpm kitr add tailwind
```

`kitr add` installs the package and wires it into your app: the provider in `kitrrc.ts`, its config file and its `AGENTS.md` section. Import it from `kitr/tailwind`.

Built on tailwindcss.

Read the guide at https://kitr.dev/packages/tailwind.

Part of [kitr](https://kitr.dev), the TypeScript framework where everything is an add-on. MIT licensed.
